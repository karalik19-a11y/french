# Как установить «Le Français» на iPhone и пользоваться без перебоев

Это приложение — **PWA (веб-приложение)**. Его нет в App Store, и это нормально:
оно устанавливается прямо из браузера Safari за минуту, сидит на домашнем экране
со своей иконкой, открывается на весь экран и **работает без интернета**.

Путь состоит из трёх частей:

1. [Разовая подготовка — включить адрес приложения](#часть-0-разовая-подготовка-делается-один-раз)
2. [Установка на iPhone](#часть-1-установка-на-iphone-5-шагов)
3. [Правила спокойной работы без перебоев](#часть-2-как-пользоваться-без-перебоев)

Плюс в конце — [таблица решения проблем](#если-что-то-пошло-не-так).

## Часть 0. Разовая подготовка (делается один раз)

Чтобы iPhone мог скачать приложение, ему нужен постоянный адрес в интернете по
**https://** — иначе iOS не разрешит ни установку, ни офлайн-режим. Самый простой
способ — бесплатный GitHub Pages прямо из этого репозитория.

**Делает владелец репозитория, с компьютера или телефона:**

1. Откройте репозиторий: <https://github.com/karalik19-a11y/french>
2. Вкладка **Settings** → слева раздел **Pages**.
3. В блоке **Build and deployment**:
   - **Source** → выбрать **Deploy from a branch**;
   - **Branch** → выбрать **main** и папку **/ (root)** → нажать **Save**.
4. Подождите 1–2 минуты. Сверху той же страницы появится зелёная плашка:
   **Your site is live at `https://karalik19-a11y.github.io/french/`**.
5. Проверьте из браузера, что адрес открывается и показывает заставку приложения.

> Дальше приложение живёт по адресу **<https://karalik19-a11y.github.io/french/>**.
> Любое обновление кода в ветке `main` само попадёт на телефон при следующем
> открытии приложения с интернетом — ничего переустанавливать не нужно.

## Часть 1. Установка на iPhone — 5 шагов

> Важно: на iPhone веб-приложения устанавливаются **только через Safari**
> (не через Chrome или другой браузер) — таково правило iOS.

1. **Откройте Safari** и перейдите по адресу
   `https://karalik19-a11y.github.io/french/`
   (проще всего — отправить себе ссылку в мессенджер и тапнуть по ней).
2. **Дождитесь полной загрузки**: заставка с кольцом исчезнет и откроется
   главный экран. Это важно — в этот момент приложение скачивает на телефон
   все свои базы (около 3000 слов, 256 глаголов, уроки, тексты), чтобы потом
   работать без сети.
3. Нажмите кнопку **«Поделиться»** — квадратик со стрелкой вверх на нижней
   панели Safari.
4. В открывшемся меню **пролистайте вниз** и нажмите
   **«На экран "Домой"»** (Add to Home Screen).
5. Нажмите **«Добавить»** в правом верхнем углу.

Готово: на домашнем экране появилась иконка **Le Français** (тёмная, с буквой F
в золотом кольце).

### Первый запуск

1. Не выключая интернет, тапните по новой иконке. Приложение откроется
   **на весь экран, без адресной строки** — как обычное приложение.
2. Спокойно откройте по очереди главные разделы (Курс, Словарь, Спряжения,
   Чтение) — так всё точно закэшируется. Достаточно 20–30 секунд.
3. Всё. Интернет больше не нужен: включайте авиарежим и проверяйте —
   всё открывается и озвучивается.

## Часть 2. Как пользоваться без перебоев

### Три «не» — чтобы не потерять прогресс

Весь прогресс (выученные карточки, стрик, достижения) хранится **на самом
телефоне**, внутри приложения. Отсюда три железных правила:

1. **Не удаляйте иконку с домашнего экрана.** Удаление иконки = удаление
   приложения **вместе со всем прогрессом**. Вернуть можно только из
   резервной копии (см. ниже).
2. **Не чистите данные сайтов.** Кнопка Настройки → Safari →
   **«Очистить историю и данные сайтов»** сотрёт и прогресс приложения.
   Чистить историю — только через «Очистить историю» с выбором, либо просто
   не трогать.
3. **Не пользуйтесь приватным режимом Safari** при установке и первом запуске —
   в нём данные стираются при закрытии вкладки.

### Резервная копия — ваша страховка

В приложении есть встроенный экспорт. Раз в пару недель (и перед всякой
чисткой телефона):

1. Откройте раздел **Профиль**.
2. Нажмите **«Резервная копия» → Экспорт** — скачается один JSON-файл.
3. Сохраните его в **Файлы → iCloud Drive** (или отправьте себе в мессенджер).
4. Если что-то случилось — заново установите приложение и в том же разделе
   Профиля выберите **Восстановление** и укажите файл. Прогресс вернётся
   целиком.

### Озвучка на iPhone

- Озвучка работает через встроенные голоса iOS, поэтому **звучит и офлайн**.
- Если голос кажется роботизированным, скачайте красивый французский голос:
  **Настройки → Универсальный доступ → Проговаривание → Голоса → Французский →**
  скачайте, например, **Amélie, Audrey или Thomas** (варианты «Улучшенный» /
  «Премиум» звучат заметно натуральнее). После скачивания приложение подхватит
  голос само.
- **Нет звука?** Проверьте три вещи: боковой переключатель бесшумного режима
  (в тишине iOS глушит и веб-звук), громкость кнопками, и что вы хотя бы раз
  тапнули по экрану после открытия (iOS разблокирует звук только после
  первого касания).

### Обновления

- Приложение обновляется **само**: при открытии с интернетом оно тихо скачивает
  новую версию, а офлайн просто работает из кэша. Ничего нажимать не нужно.
- Если подозреваете, что версия старая: откройте приложение с интернетом,
  подождите пару секунд, полностью закройте его (свайп вверх из переключателя
  приложений) и откройте снова.

### Повседневные мелочи

- Запускайте приложение **с иконки**, а не из истории Safari — так у него
  отдельное хранилище, которое iOS не трогает.
- Стрик и дневная цель считаются по часам телефона — интернет для них не нужен.
- Если анимации тормозят на старом айфоне или хочется поспокойнее:
  **Профиль → Анимации → выкл.** Тема (тёмная/светлая) — там же.
- Приложение занимает всего несколько мегабайт — чистить его «для места»
  не нужно.

## Если что-то пошло не так

| Симптом | Причина | Решение |
|---|---|---|
| Открывается как вкладка Safari, а не на весь экран | Установили не через Safari (например, из Chrome) | Удалите иконку и установите заново, начиная с шага 1 Части 1, **только в Safari** |
| В меню «Поделиться» нет пункта «На экран "Домой"» | Пункт ниже по списку | Пролистайте меню «Поделиться» вниз — он там |
| Офлайн пишет «нет сети» / пустой экран | Приложение ни разу не открывалось с интернетом до конца загрузки | Откройте с интернетом, дождитесь главного экрана, полистайте разделы |
| Не озвучивает слова | Бесшумный режим / нет французского голоса / звук заблокирован | Включите звук переключателем, скачайте голос (см. раздел «Озвучка»), тапните по экрану |
| Прогресс пропал | Чистили данные сайтов или удалили иконку | Часть 2 → «Резервная копия → Восстановление». Без файла копии восстановить нечего — начните делать экспорт регулярно |
| Старая версия, хотя приложение обновили в репозитории | Кэш ещё не успел обновиться | Открыть с интернетом → полностью закрыть приложение → открыть снова |
| Иконка выглядит как скриншот страницы | Старая версия без PNG-иконки | Обновление уже внесено в код — после слияния в `main` и следующего запуска с интернетом иконка станет нормальной |

## Частые вопросы

- **Нужен ли интернет каждый день?** Нет. Интернет нужен только для установки,
  обновлений и скачивания новых голосов. Учиться можно полностью офлайн —
  хоть в метро, хоть в самолёте.
- **А если поменять телефон?** Сделайте Экспорт резервной копии в Профиле,
  установите приложение на новом айфоне по этой инструкции и сделайте
  Восстановление из файла.
- **Это безопасно?** Приложение — просто статический сайт из вашего
  репозитория. Никуда ничего не отправляет: прогресс живёт только на телефоне.
