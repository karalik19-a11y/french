# Le Français — для Дани

Личное приложение для изучения французского **с нуля до C1**. Внутри — полная база: 256 глаголов × 15 времён, около 3000 слов с IPA и примерами, 55 уроков грамматики, чтение оригиналов, диалоги с озвучкой, 115 идиом, фонетика и методика. Всё связано интервальным повторением (SM-2), дневной целью и стриком.

Оформление — «Nuit parisienne»: глубокий navy, слоновая кость, шампанское, бордо и лаванда, редакционная антиква для французского текста и гротеск для интерфейса. Никаких эмодзи — только рисованные SVG-иконки.

## Запуск

Приложение статическое, сборка не нужна:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# открыть http://localhost:8080
```

Сервер желателен: по `file://` браузеры блокируют localStorage, service worker и часть озвучки.

## Интерфейс

- **Навигация.** На телефоне — стеклянная плавающая панель из пяти разделов и верхняя панель со стриком; на планшете и десктопе (≥1080px) — боковая колонка, сгруппированная по задачам дня. Учтены safe-area и вырез экрана.
- **Темы.** Тёмная «Nuit parisienne», светлая «Ivoire» и «как в системе»; выбор применяется до первой отрисовки, без вспышки.
- **Движение.** Пружинные переходы, каскадное появление, счётчики, отклик на нажатие. Анимации отключаются одной кнопкой и уважают `prefers-reduced-motion`.
- **Офлайн и установка.** Service worker кэширует оболочку, иллюстрации и базы: приложение работает без сети и бесплатно ставится на iPhone через Safari → «Поделиться» → «На экран Домой» (PWA, App Store не нужен).
- **Данные.** Прогресс живёт только в localStorage. В профиле — экспорт одним JSON-файлом, восстановление из него и два уровня сброса.
- **Клавиатура.** 1–4 или A–D — ответ, Enter — дальше, пробел — перевернуть карту, стрелки — оценки, Esc — выход, Ctrl/⌘+K — поиск по словарю, `?` — справка по сочетаниям.

## Структура

```
index.html          разметка оболочки, атмосферный фон, заставка
manifest.webmanifest, sw.js, icons/   PWA: манифест, service worker, иконка
css/
  style.css         токены темы, база, фон, оболочка, утилиты
  components.css    кнопки, карточки, списки, формы, кольца, полосы, тосты, листы
  screens.css       стили экранов (главная, курс, словарь, колода, чтение…)
  motion.css        ключевые кадры, переходы экранов, prefers-reduced-motion
js/
  icons.js          набор SVG-иконок и декоративные элементы
  utils.js          хелперы: $, esc, norm, md, store, даты, кольца, полосы, бейджи
  speech.js         озвучка через Web Speech API
  srs.js            SM-2: карточки, интервалы, история, экспорт
  activity.js       счётчики, избранное, навыки, достижения
  ui.js             тосты, листы, подтверждения, тема, движение, параллакс
  core.js           состояние, оболочка, роутер, доступ к уровням, сессии
  exercises.js      генераторы вопросов и движок сессий
  screen_home.js    главная
  screen_learn.js   курс, уровни, грамматика, спряжения
  screen_library.js библиотека, чтение, диалоги, идиомы, фонетика, методика
  screen_practice.js тренажёр и колода карточек
  screen_vocab.js   словарь и статья слова
  screen_you.js     прогресс и профиль
  main.js           запуск, service worker, установка, горячие клавиши
data/               базы: глаголы, лексика по уровням, грамматика, идиомы,
                    фонетика, чтение, диалоги, курс, методика
scripts/            gen_verbs.py — генератор таблиц спряжений
```

Роутер хеш-based: `#/home`, `#/course`, `#/course/lvl/2`, `#/trainer`, `#/cards/new`, `#/vocab`, `#/vocab/maison`, `#/verbs/aller`, `#/grammar/articles`, `#/reading/r1`, `#/dialogues/d1`, `#/idioms`, `#/phon`, `#/method`, `#/progress`, `#/library`, `#/profile`. Неизвестный адрес мягко уводит на главную, ошибка экрана показывается отдельным состоянием с кнопкой повтора.

## Технологии

Чистые HTML, CSS и JavaScript — без сборки и зависимостей. Озвучка — Web Speech API (нужен французский голос в системе; приложение предупреждает, если его нет). Хранение — localStorage.

Перегенерация спряжений: `python3 scripts/gen_verbs.py`
