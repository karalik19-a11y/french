# Французский для Дани 🇫🇷

Личное приложение для изучения французского языка **с нуля до C1** — без геймификации ради геймификации, только техники с доказанной эффективностью: интервальное повторение (SM-2), понятный вход (95%), активное припоминание, shadowing, вытолкнутый выход.

## Запуск

Приложение полностью статическое — сервер не обязателен, но желателен (для TTS и fetch):

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# открыть http://localhost:8080
```

## Что внутри

| Раздел | Содержимое |
|---|---|
| **Курс** | 8 уровней (A1 старт → C1), 25 юнитов, каждый закрывается тестом ≥80% (или включите свободную навигацию) |
| **Тренажёр** | SRS на SM-2: карточки возвращаются прямо перед забыванием; оценки «забыл / трудно / хорошо / легко»; стрик, дневная цель, экспорт/импорт прогресса |
| **Спряжения** | 256 глаголов × 15 времён (включая passé simple, subjonctif imparfait/plus-que-parfait, impératif, возвратные с согласованием), озвучка каждой формы, тренировки |
| **Грамматика** | 55 уроков A1→C1: артикли → subjonctif → participe passé → gérondif → косвенная речь → passé simple → ne explétif → регистры — с примерами, озвучкой и квизами (230 вопросов) |
| **Чтение** | 5 градуированных текстов A1→C1 + 4 классических в оригинале (Лафонтен, Мопассан «La Parure», Гюго, Вольтер «Candide»): клик по слову = перевод, озвучка текста, вопросы |
| **Диалоги** | 12 ситуативных диалогов A1→C1 с пословной озвучкой и режимом **shadowing** (повтор за диктором) |
| **Идиомы** | 115 пословиц, идиом и разговорных формул с дословным переводом + викторина |
| **Фонетика** | 15 звуков с подсказками для русскоязычных, правила чтения/liaison, 20 минимальных пар, 10 скороговорок (3 скорости) |
| **Методика** | 10 техник обучения с обоснованием, планы на 30 и 60 минут, недельный ритм, база из 35+ учебников и ресурсов (CLE, Alter Ego, Édito, Assimil, Bescherelle, InnerFrench, TV5MONDE...) |

## Словарная база

~3000 записей A1→C1 (слово, перевод, род, IPA, пример с переводом): тематические словари + B2/C1-лексика: экономика, формальный регистр, книжные обороты, связки, суд/право, эмоции.

## Технологии

Чистый HTML/CSS/JS без сборки и зависимостей. Озвучка — Web Speech API (нужен французский голос в системе). Прогресс — localStorage.

## Дизайн

Мобильный интерфейс в духе iOS: нижний плавающий таб-бар из 5 разделов (Главная · Курс · Тренажёр · Ещё · Прогресс), стеклянная шапка с компактным заголовком при прокрутке, крупные заголовки, карточки с мягкими тенями, диалоги в виде чата-мессенджера, фокус-режим на время упражнений (таб-бар скрывается). Палитра — тёплая бумага + bleu de France, французский текст набран serif'ом (New York). Светлая и тёмная темы переключаются автоматически. На iPhone приложение можно добавить на экран «Домой» (meta apple-mobile-web-app).

## Структура

```
data/       базы данных (verbs.js генерируется)
scripts/    gen_verbs.py — генератор спряжений
js/         utils, speech (TTS), srs (SM-2), exercises, app
css/        style.css
```

Перегенерация спряжений: `python3 scripts/gen_verbs.py`
